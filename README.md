## ✨ Why Office Tools?

- **100% free** — no sign-up, no watermark, no limits on how many files you use.
- **No installation** — works in any modern browser on phone, tablet or computer.
- **Your files stay with you** — the tools run inside your browser, so your PDFs and images are not uploaded to a server. *(Exception: the optional Gemini AI OCR sends page images to Google; see the OCR section.)*
- **Hindi friendly** — Hindi OCR and a Mangal/Unicode ⇄ Kruti Dev converter.
- **Fast and simple** — pick a tool, add your file, download the result.

## 🔍 OCR Guide

- **Tesseract (free):** works in your browser. Best for printed text. Supports **English, Hindi, and English + Hindi**.
- **Gemini AI (optional):** much better for handwriting. You use **your own free Gemini API key**, and page images are sent to Google, so avoid it for confidential documents.

**How to get your free Gemini API key (no technical knowledge needed):**
1. Open [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Sign in with your Google (Gmail) account.
3. Accept the terms if asked.
4. Click **Create API key** (choose any project, or "Create in new project").
5. Click **Copy** next to the key, return to Office Tools's OCR tool, choose *Gemini AI* and paste it.

Your key is saved only in your own browser. Never share it. The free plan has daily limits, so if it stops working, try later.
- Enter page numbers like `1-3` to scan only some pages. Leave it empty to scan all.
- Large PDFs can take a few minutes. The first run needs internet to load the OCR engine.
- OCR can make mistakes, especially with handwriting — **always proofread** important text.

## 💡 Tips

- **Need a smaller file for a form?** Use *JPEG Export* (size target) or *Compress PDF*.
- **Photo sideways?** Use *Rotate & Flip*.
- **Old Kruti Dev text?** Use *Hindi Font Converter* to get Unicode.
- Compressing a PDF rebuilds pages as images, so selectable text may be lost. Keep a copy of your original.
- On a slow connection, give the page a moment to load its libraries.

## ❓ FAQ

**Is it really free?** Yes, completely.

**Are my files uploaded?** The tools process files in your browser. Only the optional Gemini OCR sends data to Google.

**Does it work on mobile?** Yes, in any modern browser.

**Is there a file size limit?** No fixed limit, but very large files depend on your device's memory.

**Something broke. What now?** Refresh the page and retry. If it persists, open an issue on this repository.
